## Deferred: alternative HbA1c thresholds

The brief for this item allows a threshold sensitivity view only with a credible clinical source. The analysis already uses the ADA diagnostic criterion of 6.5 percent. No source has been added that supports a different diagnostic threshold for undiagnosed diabetes, and the prediabetes range is a different question from undiagnosed diabetes. Adding an unsupported threshold would look like a sensitivity analysis without being one, so it is not included. The threshold is one value in `configs/analysis.yml`, so the analysis can be rerun if a source is agreed.

## Known gaps and limits

- No Tableau workbook (manual checkpoint for Vijay).
- The workbook stores calculated results next to its formulas, but a previewer that ignores formulas shows the stored values, which reflect the last build.
- The descriptive findings do not show why the gap exists and are not causal. The models are not clinical risk models.
- Small groups have wide intervals; the pooled Other/Multiracial group is flagged.
