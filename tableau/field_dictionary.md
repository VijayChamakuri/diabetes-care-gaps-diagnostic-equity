# Field dictionary

Generated by `nhanes-diabetes tableau`. One section per extract in `tableau/data/`. Public NHANES 2017-2018 survey aggregates; no respondent-level rows.

## care_gap_summary.csv

7 rows.

| Field | Type | Meaning |
|---|---|---|
| `group` | text | Race and ethnicity group, or All groups. |
| `is_all_groups` | boolean | True for the All groups row. Use it to separate the total from the group rows. |
| `hba1c_positive_respondents` | number | Unweighted respondents meeting the HbA1c criterion (the denominator group). |
| `undiagnosed_respondents` | number | Unweighted respondents meeting the criterion who were never told they have diabetes. |
| `weighted_denominator` | number | Survey-weighted people meeting the HbA1c criterion. |
| `weighted_undiagnosed` | number | Survey-weighted people meeting the criterion who were never told they have diabetes. |
| `undiagnosed_share` | number | Weighted undiagnosed share of people meeting the HbA1c criterion (0 to 1). |
| `ci_low` | number | Lower bound of the 95% logit interval, or of the metric interval in model_tradeoffs.csv. |
| `ci_high` | number | Upper bound of the 95% logit interval, or of the metric interval in model_tradeoffs.csv. |
| `effective_n_kish` | number | Kish effective sample size of the group. |
| `small_sample_warning` | text | SMALL SAMPLE when the group has fewer than 30 respondents or an effective n under 30, else OK. |
| `difference_vs_reference` | number | Undiagnosed share minus the reference group's share (0 to 1 scale). Empty for the reference group and All groups. |
| `diff_ci_low` | number | Lower bound of the 95% interval for the difference. |
| `diff_ci_high` | number | Upper bound of the 95% interval for the difference. |
| `ratio` | number | Undiagnosed share divided by the reference group's share. |
| `ratio_ci_low` | number | Lower bound of the 95% interval for the ratio. |
| `ratio_ci_high` | number | Upper bound of the 95% interval for the ratio. |
| `p_value` | number | Unadjusted p-value for the difference. |
| `p_value_holm` | number | Holm-adjusted p-value across the comparisons with the reference group. |
| `analysis_type` | text | confirmatory for the one pre-specified comparison, exploratory for the rest. |
| `review_label` | text | Reference group, Pre-specified comparison, or Exploratory with the Holm result at the display threshold. |

## model_tradeoffs.csv

320 rows.

| Field | Type | Meaning |
|---|---|---|
| `model` | text | Model identifier from model_specification.csv. |

| `model_description` | text | Plain-English model description. |
| `group` | text | Race and ethnicity group, or All groups. |
| `label` | text | Training label (diagnosed or hba1c_pos), or diagnosed minus hba1c_pos for paired comparisons. |
| `metric` | text | auc, auc_difference, sensitivity, specificity, false_positive_rate, ppv, npv or specificity_cost. |
| `estimate` | number | Value of the metric. Rates and shares are on a 0 to 1 scale. |
| `ci_low` | number | Lower bound of the 95% logit interval, or of the metric interval in model_tradeoffs.csv. |
| `ci_high` | number | Upper bound of the 95% logit interval, or of the metric interval in model_tradeoffs.csv. |
| `unit` | text | proportion, auc or percentage points (0 to 1 scale). |
| `small_sample_warning` | text | SMALL SAMPLE when the group has fewer than 30 respondents or an effective n under 30, else OK. |
