# Tableau package

**Status: no Tableau workbook has been built or published. This repository contains no `.twb`, no `.twbx` and no Tableau Public URL, so nothing here claims a Tableau dashboard.** The reproducible BI artifact is the offline HTML dashboard in [`../dashboard/index.html`](../dashboard/index.html). The Excel quality review is in [`../excel/`](../excel/).

This folder prepares what is needed to build a workbook and to check it once built.

| File | Purpose |
|---|---|
| `data/care_gap_summary.csv` | One row per group: weighted undiagnosed share, interval, unweighted and effective n, warning flag, comparison with the reference group |
| `data/model_tradeoffs.csv` | Long format: model, group, label, metric, estimate and interval |
| `data/cohort_flow.csv` | One row per cohort step |
| `field_dictionary.md` | Generated dictionary of every field in every extract |
| `calculated_fields.md` | Calculated fields and parameters to create in Tableau |
| `build_guide.md` | Three pages, filters, tooltips and actions to build, mirroring the HTML dashboard |
| `expected_kpis.csv` | Values each KPI worksheet must reproduce |
| `qa_checklist.md` | Checks to complete before any Tableau claim |

The extracts are generated by `nhanes-diabetes report` from `outputs/tables`, contain aggregates only and are checked for drift by `make check-readme`. Hyper extracts are not produced; connect Tableau to the CSVs.

## Manual checkpoint (Vijay)

1. Open Tableau Desktop or Tableau Public and connect the three CSVs in `data/`.
2. Build the three pages from `build_guide.md` using the fields in `calculated_fields.md`.
3. Compare every KPI with `expected_kpis.csv` and complete `qa_checklist.md`.
4. Save the workbook as `.twbx` in this folder, or publish it to Tableau Public.
5. Only then add the workbook path or the public URL to this file and change the main README to say a Tableau version exists. Until then, do not claim one.
